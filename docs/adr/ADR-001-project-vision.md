# ADR-001: Project Vision

- Status: Accepted
- Date: 2026-09-19
- Decision Maker: Rafael Martín Rodríguez

## Context

EngineRoom is intended to become a long-term engineering repository that supports continuous learning, documents technical decisions and demonstrates professional software engineering practices.

Without a clearly defined vision, future architectural decisions could become inconsistent, reducing the educational and professional value of the repository as it grows.

## Decision

EngineRoom will be maintained as a long-term engineering knowledge repository.

The project will prioritize:

- Practical learning through implementation.
- Professional software engineering practices.
- High-quality technical documentation.
- Incremental development.
- Long-term maintainability.
- Continuous improvement.

The repository is intended to serve both as a personal learning platform and as a professional portfolio demonstrating engineering skills.

## Consequences

### Positive

- Establishes a clear long-term direction.
- Supports consistent architectural decisions.
- Improves maintainability.
- Reinforces the repository as a professional portfolio.
- Encourages disciplined engineering practices.

### Negative

- Requires continuous maintenance of documentation.
- Slower initial development due to documentation effort.
- Demands higher discipline before adding new content.
