# Programming

Programming is the foundation of modern software engineering.

This domain contains programming languages, core programming concepts and practical projects that build the skills required to design, implement and maintain software systems.

The content is organized by technology and follows a progressive learning path, from fundamental concepts to advanced topics.

## Planned Technologies

- Python
- Java
- JavaScript
- TypeScript
- Go
- Rust
- C
- C#

Each technology is developed independently while following the engineering standards defined for EngineRoom.

## Learning Philosophy

Every technology combines:

- Theory
- Practical examples
- Hands-on exercises
- Guided solutions
- Small projects
- Best practices

The objective is not only to learn syntax but to understand how professional software is designed and developed.
