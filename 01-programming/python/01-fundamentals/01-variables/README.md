# Variables

## Overview

Variables are one of the most fundamental concepts in programming.

They allow programs to store, update, and manipulate information while they run. Every application—from a simple calculator to a modern AI system—relies on variables to process data.

In this module, you will learn how Python stores values, how to work with different data types, and how to interact with users through console input and output.

---

## Learning Objectives

After completing this module, you will be able to:

- Create and use variables.
- Understand Python's built-in data types.
- Read input from users.
- Display formatted output.
- Convert values between different data types.
- Follow basic naming conventions and best practices.
